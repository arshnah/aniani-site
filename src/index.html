A desktop GUI, not a browser tab or an Electron wrapper. Discover dashboard, resume-from-timestamp, AniList sync, Discord Rich Presence, and a manga/comic/ebook reader built in. Rust, egui/eframe.

what it does

A discover dashboard -- Continue Watching, Trending, and Popular cover-art rows, click one to jump straight to search -- then an episode list, then play, with resume-from-timestamp. AniList tracker sync and Discord Rich Presence built in, not bolted on after.

This is a full Rust rewrite of an earlier Python/PyQt6 version, not a port. Confirmed the actual perf gap before claiming one: same egui code, unoptimized debug build vs. release, showed multi-second slow-frame stalls decoding cover art on startup in debug and zero in release.

features

mpv / VLCSwitchable from the top bar. mpv over its JSON IPC socket, VLC over its HTTP control interface with a fresh random port and password every launch.
Downloads & offlineffmpeg remuxes HLS to mp4, live progress from ffmpeg's own pipe, cancellable. A library of what's already saved, playable with no network at all.
AniList syncTwo-way. Optional push on finishing an episode, off by default. Pull happens automatically once connected.
Discord Rich PresenceCover art, live elapsed time, and a watch link, during playback -- plus a manual movie/TV tracker for anything you're watching outside aniani.
Manga & book readerCBZ, CBR, PDF, EPUB, and MangaDex's own public API, in the same app.
Continue watchingBuilt from local watch history. Clicking a card plays straight from disk if that episode's already downloaded, no re-resolving a live stream.

install

Grab the latest build from Releases -- Windows gets aniani.exe, Linux gets a tarball. Either way you'll also want mpv/vlc, ffmpeg, curl_chrome136, and qbittorrent-nox on PATH. Building from source instead:

# clone and build
git clone --branch rust-remake https://github.com/arshnah/aniani.git
cd aniani
cargo build --release

platform support

Built and daily-driven on Linux (Arch/Hyprland). Windows compiles and runs on real hardware, confirmed on two separate machines. macOS is untested and not a current target.
